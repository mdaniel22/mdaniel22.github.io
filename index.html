Selected work

Interferometric frequency-domain gradiometry (I-FDG)

PhD · Geophysical Journal International, 2026

Problem
Elastic full waveform inversion (PDE-constrained inversion of wave simulations) needs a long-wavelength shear-wave velocity starting model.
Approach
Extract sub-2 Hz coherent wavefields from long ambient ocean-floor sensor recordings by cross-correlation (seismic interferometry). Extend wavefield gradiometry from the time domain to the frequency domain, and stack virtual-source gathers for higher SNR and depth sensitivity.
Result
On a synthetic 3-D elastic model with salt bodies and strong velocity contrasts, estimates correlate strongly with conventional dispersion-curve analysis.
Stack
Python · Madagascar · HPC (Mines Wendian cluster)

Paper (DOI)Code: ifdg repo forthcoming

Trans-dimensional Bayesian inversion with uncertainty

PhD · In progress

Problem
Mapping frequency-domain gradiometry measurements to depth profiles of velocity is non-unique. A single best-fit model hides its uncertainty.
Approach
Bayesian inference where model complexity is itself inferred (trans-dimensional Bayes, sampled with reversible-jump MCMC). The sampler returns a posterior over depth-domain velocity profiles rather than one answer.
Result
Preliminary results show robust agreement with synthetic salt models.
Stack
Python · MCMC

Code not yet public

Hybrid CNN + RNN for learning subsurface fields

PETRONAS · Project lead · SEG/IMAGE 2022

Problem
Learning subsurface property fields from wave data (velocity model building) with pure CNNs demands large training sets.
Approach
A CNN constrained by an RNN, combined with decision trees. Applied to the synthetic SEAM model and to Gulf of Mexico Block 26 field data.
Result
Required ~80% less training data than pure-CNN approaches.
Stack
CNNs · RNNs · decision trees

Fiber-optic sensing and imaging in producing wells

PETRONAS / Viridien · Project manager · EAGE 2019

Problem
Image the subsurface offshore Borneo using fiber-optic cable as a dense array of thousands of sensors (DAS), in data heavily contaminated by production noise.
Approach
Managed a USD 1M+ acquisition and processing project. Denoised 50,000+ source shots with f-x filtering and imaged them with reverse time migration with multiples. Fused the result with ocean-floor node data.
Result
Zero production downtime. A co-developed multi-parameter fiber sensor is projected to save ~USD 500k per installation.
Stack
Geovation (Viridien) · f-x filtering · RTM

Simulation-driven survey design

PETRONAS · Project lead · OTC Asia 2022

Problem
Choose a sensor acquisition geometry for an ultra-deepwater salt play offshore Gabon (Block F12), where every survey day is costly.
Approach
Ran illumination and survey-geometry studies with pseudo-analytical wave modeling in place of finite-difference simulation, and compared the two methods.
Result
The recommended acquisition geometry saved an estimated ~USD 200k per day.
Stack
Pseudo-analytical and finite-difference wave modeling · illumination analysis
